# SOLIDWORKS-Microfluidics-Device
Projects that showcase my experience and familiarity of using SOLIDWORKS.

## Overview

This project involved the design and modelling of a **microfluidic device** using SOLIDWORKS. The device incorporates internal microchannels designed to control and direct fluid flow through defined pathways.

The project provided hands-on experience in **3D CAD modelling, parametric design, and microfluidic device design** within a biomedical engineering context.

## Design

The device was modelled from scratch in SOLIDWORKS using sketches and parametric features to develop the device body and internal fluid channels.

### Key Design Features

- Microfluidic channels
- Defined inlet and outlet points
- Controlled channel geometry
- Parametric CAD features for design modification
